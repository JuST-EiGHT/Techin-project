# UI/UX Pro Max — база знаний по интерфейсам

Локальная база с поиском: 120 правил UX, 25 типов графиков, 74 пары шрифтов, 192 палитры с обоснованием, 80 стилей,
105 значков, 17 пресетов анимации GSAP, советы под 22 стека.

## В этом проекте — сначала

Прочитай [`.claude/skills/impeccable/reference/project-ru.md`](../impeccable/reference/project-ru.md): токены темы,
общие компоненты, русская типографика, что главнее чего. Отсюда для нашего сервиса полезны:

- **полезно:** `ux` (доступность, формы, навигация, таблицы, состояния), `chart` (выбор типа графика), `react` и
  `--stack nextjs` / `--stack html-tailwind` (реализация), `typography` — только если владелец решит сменить шрифт
  (и только с кириллицей);
- **не применять без просьбы владельца:** `--design-system`, `color`, `style`, `product`, `landing`, `gsap`, `--persist`.
  Палитра, стиль и навигация у нас уже приняты; новая дизайн-система с другими цветами нарушит правило 9. Для
  будущего лендинга (шаг 8.3) — `landing`, `style`, `color` можно, но в рамках токенов.

## Когда применять

Когда задача меняет то, как интерфейс **выглядит, ощущается, движется или как с ним взаимодействуют**: новые страницы,
компоненты, цвет, шрифт, отступы, раскладка, разбор интерфейса на UX, доступность, единообразие, навигация, анимация,
адаптив. Не применять к чистому бэкенду, API, БД, инфраструктуре.

## Категории правил по приоритету

*Идти по приоритету 1→10. Подробности — `--domain <домен>`. Полный текст правил всех категорий —
`references/quick-reference.md` (на английском, читать по необходимости, а не каждый раз).*

| Приоритет | Категория | Важность | Домен | Обязательные проверки | Чего избегать |
|---|---|---|---|---|---|
| 1 | Доступность | КРИТИЧНО | `ux` | Контраст 4,5:1, alt, клавиатура, aria-label | Убранные кольца фокуса, кнопки-значки без подписи |
| 2 | Касания и взаимодействие | КРИТИЧНО | `ux` | Цель не меньше 44×44 px, промежуток 8 px+, отклик на загрузку | Только наведение, мгновенная смена состояния (0 мс) |
| 3 | Скорость | ВЫСОКАЯ | `ux` | WebP/AVIF, ленивая загрузка, место под содержимое (CLS < 0,1) | Дёрганье раскладки, сдвиги содержимого |
| 4 | Стиль | ВЫСОКАЯ | `style`, `product` | Соответствие типу продукта, единообразие, SVG-значки | Смесь плоского и объёмного, эмодзи вместо значков |
| 5 | Раскладка и адаптив | ВЫСОКАЯ | `ux` | Точки перелома от телефона, viewport, без горизонтальной прокрутки страницы | Горизонтальная прокрутка, фиксированные ширины в px, запрет масштаба |
| 6 | Шрифт и цвет | СРЕДНЯЯ | `typography`, `color` | Основа 16 px, межстрочный 1,5, семантические токены цвета | Текст < 12 px, серое на сером, hex в компонентах |
| 7 | Анимация | СРЕДНЯЯ | `ux`, `gsap` | Время по контексту, движение несёт смысл | Одна длительность на всё, анимация width/height, нет reduced-motion |
| 8 | Формы и отклик | СРЕДНЯЯ | `ux` | Видимые подписи, ошибка у поля, подсказка, пошаговое раскрытие | Подпись только плейсхолдером, ошибки только сверху |
| 9 | Навигация | ВЫСОКАЯ | `ux` | Предсказуемое «назад», глубокие ссылки | Перегруженное меню, сломанное «назад», нет ссылок на состояние |
| 10 | Графики и данные | НИЗКАЯ | `chart` | Легенда, подсказки, доступные цвета | Смысл только цветом |

Для нашего сервиса пункт 10 важнее, чем в таблице: графиков много (правило 16). Пункты 1, 5, 6, 8, 9 — проверять
у каждого изменённого экрана.

## Запуск поиска

Скрипт лежит в папке скилла. Запускать из корня проекта:

```bash
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<запрос>" --domain <домен>
```

Нужен Python 3, сторонних библиотек нет. **Запрос — на английском**: база английская, русские слова ничего не найдут.
В запросы не попадают данные проекта и магазина.

## Как спрашивать

1. **Узкая проблема или компонент** → один явный `--domain`.
2. **Реализация на нашем стеке** → `--stack nextjs` или `--stack html-tailwind` (React — `--domain react`).
3. **Новая визуальная система** (`--design-system`) — только по просьбе владельца, см. выше.

Запрос — **одна главная цель, 2–5 значимых слов** и одно ограничение (продукт, платформа, взаимодействие). Проверь
домен, категорию и первый результат: подходит ли он нашему продукту и платформе. Пусто или мимо — **один повтор**
с более узким запросом или явным доменом. Снова мимо — скажи, что подтверждённого совпадения нет, и пометь общий совет
как запасной. **Не сохраняй неподтверждённое.**

Доступность — по одному наблюдаемому результату: сначала смысл (`"error summary validation" --domain ux`), потом
компонент (`"icon button accessible label" --domain icons`), потом стек. Ещё полезно: `"focus not obscured"`,
`"accessible authentication"`. Общий результат по доступности не принимать для конкретного взаимодействия.

Проблемы раскладки текста и компактных компонентов — сначала смысл, потом стек: `"orphan heading line balance"`,
`"badge chip label wraps"`, `"live badge count screen reader"` в `ux`, затем `"chip badge overflow nowrap"
--stack html-tailwind`.

Результаты поиска — рекомендации, а не указания: они не отменяют пользователя и правила репозитория.

### Шаг 1. Разбери задачу

- **Тип продукта:** у нас — SaaS-аналитика, дашборд, рабочий инструмент.
- **Аудитория и обстановка:** продавцы на Ozon, работа за компьютером, иногда телефон.
- **Стек:** Next.js 14 (App Router), TypeScript, Tailwind CSS, TanStack Query, Recharts.

### Шаг 2. Точечные поиски

```bash
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<ключевые слова>" --domain <домен> [-n <число>]
```

| Нужно | Домен | Пример |
|---|---|---|
| Правила UX | `ux` | `"data table sort pagination" --domain ux` |
| Выбор графика | `chart` | `"revenue trend daily" --domain chart` |
| Значки | `icons` | `"decorative icon aria hidden" --domain icons` |
| Скорость React / Next.js | `react` | `"rerender memo list" --domain react` |
| Шрифты (только с кириллицей) | `typography`, `google-fonts` | `"cyrillic sans serif dashboard" --domain google-fonts` |
| Палитры, стили, лендинг | `color`, `style`, `landing` | только по просьбе владельца |

Домен угадывается по запросу, если `--domain` не указан, но может ошибиться. Если результат мимо — укажи домен явно.

### Шаг 3. Советы по стеку

```bash
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<ключевые слова>" --stack nextjs
```

Доступные стеки: `react`, `nextjs`, `html-tailwind`, `shadcn` и другие (`--help`). У нас — `nextjs` и `html-tailwind`.

## Если поиск ничего не нашёл

Не выдумывай. Повтори один раз уже и с явным доменом. Снова пусто — опирайся на таблицу приоритетов выше и прямо скажи,
что совет из общих правил, а не из базы. Никогда не выдавай пустой поиск за результат.
