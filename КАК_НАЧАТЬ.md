# Как продолжить проект в Claude Code

Что это за проект и что из него получится — в `docs/PROJECT.md`.
Здесь — только как работать с ним дальше.

## 1. Подготовка (один раз)

1. Распакуй архив в удобную папку, например `C:\Projects\ozon-analytics`.
2. Установи **Git**, **Docker Desktop** и **Python 3.12**, если их ещё нет.
3. Установи Claude Code по официальной инструкции: https://docs.claude.com/en/docs/claude-code
4. Открой терминал в папке проекта и выполни:
   ```
   cp .env.example .env
   claude
   ```
   (в Windows вместо `cp` — `copy .env.example .env`)

Claude Code сам прочитает `CLAUDE.md` — там описан проект, правила и текущий статус.

## 2. Первое сообщение

Скопируй содержимое `docs/prompts/00_start.md` и отправь. Claude Code изучит проект,
запустит тесты и ответит, что понял. Ничего менять он на этом шаге не будет.

## 3. Дальше — по одному шагу

Открывай файлы из `docs/prompts/` по порядку из `docs/ROADMAP.md` («Рекомендуемый порядок») и отправляй по одному —
лучше каждый шаг в новой сессии. Сейчас (22.10.2026) идёт фаза 10 «Карта сервиса»: `10.1 → 10.2 → … → 10.26`
(что где будет в кабинете — `docs/SITEMAP.md`), потом 8.4a, лендинг, почта, тарифы и оплата, автоматизация.

## 4. Правила, которые помогают

- Один шаг — одно сообщение. Не проси «сделай 2.1 и 2.2 сразу».
- После шага проси: «покажи, что изменилось, и прогони тесты».
- Если что-то сломалось — опиши, что видишь, и приложи текст ошибки целиком.
- Перед большими изменениями проси сделать коммит, чтобы можно было откатиться.
- Новые изменения Ozon (как с объявленной стоимостью) просто присылай текстом и проси
  внести их в `docs/BUSINESS_LOGIC.md` §9.
