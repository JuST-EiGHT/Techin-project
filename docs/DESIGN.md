# Дизайн-система

Общие правила внешнего вида сервиса. Каждый раздел при переделке сверяется с этим файлом и берёт элементы из
`frontend/src/components/ui.tsx`, а не собирает свои. Живая витрина всех элементов в обеих темах — страница **`/design`**
(служебная, без входа, не в меню).

Шаг 10.27a (решение владельца 12.11.2026). Поправки к системе вносятся сюда, в токены и в `ui.tsx` — тогда они приходят
на все страницы сразу.

---

## 1. Откуда стиль

Референс владельца — доска Pinterest «SaaS Design» (Musemind, 42 пина просмотрены: дашборды продаж, заказов, выплат,
email-аналитики, финансов, логистики, CRM; светлые и тёмные).

**Берём:**
- светлый воздушный фон и белые карточки с тонкой рамкой и едва заметной тенью; тёмная тема — почти чёрная, без синевы;
- фиолетовый акцент — главные кнопки, выбранное, первая серия графика;
- показатель как карточка: подпись, крупная цифра, плашка изменения «▲ 12,4 %», «было …»;
- переключатели вида сегментами («Дни / Недели / Месяцы»), мягкая подложка выбранного;
- графики: плавная линия с заливкой-градиентом, парные столбцы «этот период / прошлый» (яркий и бледный), кольцевая
  диаграмма с легендой и процентами;
- таблицы в панели во всю ширину: тонкие линии, шапка на мягком фоне, статусы цветными плашками с точкой;
- воздух: отступы 20 px внутри панелей, 20 px между ними.

**Не берём:**
- 3D-иллюстрации, фото людей, градиентные «стеклянные» фоны, моноширинный «брутализм» (пины 30–32) — это лендинги
  и витрины, а не рабочий кабинет;
- аватарки и «Hi, Jenny» — у нас магазин, а не человек;
- кольца-«спидометры» без чисел и подписей — только с цифрой и переходом.

**Остаётся как было (решения владельца):** верхнее меню с выпадающими списками (10.1), фильтры (10.27), графики с
переходом в подробности (правило 16), обе темы, тёмная — по умолчанию.

## 2. Принципы

1. **Цифры — главное.** Самое крупное на экране — число, ради которого пришли. Подписи — тише.
2. **Одна панель — одна мысль.** Заголовок панели говорит, что в ней; одна строка под ним — за какой период или как
   считали. Панель в панели не кладём.
3. **Цвет — смысл, а не украшение.** Фиолетовый — действие и выбор. Зелёный — хорошо для денег, красный — плохо,
   жёлтый — внимание. Всё остальное — нейтральное.
4. **Каждая цифра ведёт дальше.** Показатель — ссылка на подробности, точка графика — на день, «Подробнее →» — на период.
5. **Нет данных ≠ 0.** Пустое состояние говорит, каких данных нет и что сделать.
6. **Одинаково везде.** Одна и та же кнопка, плашка, таблица на всех страницах. Если в двух местах «Сохранить»
   выглядит по-разному — одно из них неправильно.

## 3. Токены

Определены в `frontend/src/app/globals.css` (каналы RGB) и `tailwind.config.ts`. **В компонентах — только токены**:
без hex, без `slate-*` / `gray-*`, без `text-white` (на цветной заливке — `text-on-accent`).

### Цвета

| Токен | Тёмная | Светлая | Для чего |
|---|---|---|---|
| `bg` | `#0d0c12` | `#f4f4f9` | фон страницы |
| `card` | `#17161e` | `#ffffff` | панели, шапка, окна, выпадающие списки |
| `soft` | `#201e2a` | `#f0eefb` | второй слой: подложка сегментов, шапка таблицы, наведение, заглушки загрузки |
| `line` | `#2a2836` | `#e6e5ef` | рамки, разделители, сетка графиков |
| `fg` | `#ecebf3` | `#17151f` | основной текст, цифры |
| `muted` | `#a6a4b8` | `#5b5970` | второстепенный текст, подписи показателей |
| `faint` | `#8f8da4` | `#6b6982` | подсказки, оси графиков, «было …» |
| `accent` | `#9d84ff` | `#6639e8` | главная кнопка, выбранное, ссылки, первая серия графика |
| `on-accent` | `#0d0c12` | `#ffffff` | текст на любой цветной заливке (`accent`, `ok`, `bad`) |
| `ok` | `#3ccf8e` | `#0f7637` | прибыль, рост, «оплачен», «в наличии» |
| `bad` | `#f87171` | `#c4271b` | убыток, падение, ошибка, «просрочен» |
| `warn` | `#fbbf24` | `#b54708` | внимание, «скоро», «ожидается» |

Контраст текста `fg`, `muted`, `faint`, `accent`, `ok`, `bad`, `warn` на `card` и `bg` — не ниже 4,5:1 в обеих темах.

**Мягкие заливки** (плашки, выделение, фон предупреждения): цвет с прозрачностью `/10` — `bg-ok/10 text-ok`,
`bg-accent/10`. Наведение на строку — `bg-soft`. Выделенная строка таблицы — `bg-accent/5`.

### Ряды графиков

`chart-1` … `chart-6` — для категорий (структура расходов, доли, несколько товаров). По порядку, первый — акцент.
В Recharts — `useTokenColors()` (`c1` … `c6`). Для «хорошо / плохо» в графиках — `ok` / `bad`, а не ряды.
Сравнение с прошлым периодом — тот же цвет бледнее (`chart-6` в светлой — бледно-фиолетовый) или пунктир `muted`.

### Скругления, тени, рамки

| | Класс | Где |
|---|---|---|
| Панель, карточка показателя | `rounded-xl` (14 px) + `border border-line` + `shadow-card` | все контейнеры |
| Кнопка, поле, сегмент | `rounded-lg` (10 px) | элементы управления |
| Плашка, точка, счётчик | `rounded-full` | статусы, ▲ / ▼ |
| Всплывающее (меню, подсказка, окно) | `rounded-xl` + `shadow-pop` | поверх страницы |

Тени только эти две. Цветные полосы сбоку карточки (`border-l-4`) не используем: статус — плашкой или значком.

### Шрифт

**Inter** (вариативный, с кириллицей) из `@fontsource-variable/inter` — без запросов к Google. Включены альтернативные
цифры (`cv01`, `cv05`, `cv08`): «1» с основанием, открытые «4», «6», «9». В таблицах цифры ровными колонками
(`tabular-nums` — для `table` уже в `globals.css`; для цифр вне таблиц — класс `tabular-nums`).

| Роль | Класс |
|---|---|
| Заголовок страницы | `text-2xl font-semibold tracking-tight` (24 px) |
| Цифра показателя | `text-xl sm:text-2xl font-semibold tabular-nums` |
| Заголовок панели | `text-base font-semibold` (16 px) |
| Основной текст, таблицы, кнопки | `text-sm` (14 px) |
| Подписи, плашки, оси, «было …» | `text-xs` (12 px), `text-muted` или `text-faint` |

Подписи — с заглавной буквы, без КАПСА и разрядки (`uppercase tracking-wider` больше не используем; исключение —
плашка «СРОЧНО»). Не мельче 12 px.

### Отступы и сетка

- Шаг — 4 px. Внутри панели — `p-5` (20 px), у показателя — `p-4`. Между панелями — `gap-5` / `space-y-5`.
  Между заголовком панели и содержимым — `mb-4`.
- Страница — `p-4 md:p-6` (в `dashboard/layout.tsx`), ширина содержимого — во всю, графики и таблицы растягиваются.
- Сетка панелей: `grid gap-5 lg:grid-cols-3`, широкая панель — `lg:col-span-2`. Показатели — `StatGrid`
  (2 в ряд на телефоне, 4 — с 1024 px).

### Движение

150–200 мс на смену цвета и подложки (`transition-colors`). Без появлений при загрузке, без анимации графиков
(`isAnimationActive={false}`). `prefers-reduced-motion` отключает всё (`globals.css`).

## 4. Элементы (`components/ui.tsx`)

| Элемент | Когда |
|---|---|
| `PageHeader` | Вверху каждой страницы: название, одна строка «что здесь», действия справа; под ним — вкладки и фильтры |
| `Panel` | Любой блок: график, таблица, список. `title`, `description` (период, как считаем), `action` («Подробнее →», Excel). Таблица во всю ширину — `flush` |
| `Stat` + `StatGrid` | Ключевые цифры раздела: подпись, значение, `Delta`, `hint` («было …»), `href` в подробности, `icon` (на телефоне скрыт) |
| `Delta` | Изменение к прошлому периоду: плашка ▲ / ▼; `upIsBad` — для расходов и возвратов; `unit="п.п."` — для маржи |
| `Badge` | Статус («Оплачен», «Просрочен», «Срочно»), источник («Ozon API», «Отчёт»). `dot` — статус процесса |
| `Button`, `buttonClass` | `primary` — одно главное действие на экране; `secondary` — Excel, «Отмена» в окне; `ghost` — третьестепенное; `danger` — необратимое. `size="sm"` — в шапке панели и таблице |
| `Segmented` | Переключатель вида: показатель графика, детализация, «по товарам / складам». Не фильтр — на виду |
| `EmptyState` | Нет данных, ничего не найдено, раздел не настроен: что не так + следующее действие |
| `Skeleton` | Загрузка: заглушки той же формы, что содержимое, а не «Загрузка…» посреди страницы |
| `IconBox` | Значок в мягком квадрате: у показателя, в предупреждении, в пустом состоянии |

Уже общие и остаются:

| Что | Где |
|---|---|
| Поиск, период, «Фильтры» | `components/filters.tsx` (правило 18) |
| Подсказка графика, переход по точке, «Подробнее →» | `components/charts.tsx` (`TipBox`, `useDrill`, `MoreLink`; правило 16) |
| Цвета для графиков | `useTokenColors()` из `components/finance.tsx` |
| Окно поверх страницы, поле ввода | `components/planning/ui.tsx` (`Modal`, `input`) |
| «Обновлено …» | `components/sync.tsx` (`UpdatedAt`) |
| Копирование артикула, штрихкода | `components/copy.tsx` |
| Форматирование ₽, %, шт. | `lib/analytics.ts` (`formatMetric`) |

Значки — `lucide-react`, одной толщины, `h-4 w-4` в тексте и кнопках. Без эмодзи.

## 5. Как строится страница

### Обзор (главная, «Обзор бизнеса», «Обзор финансов», обзор планирования, сводка складов)

```
PageHeader: название · «Как идут дела у магазина» · [период] [Фильтры]
StatGrid: 4 показателя с Delta и переходом
Panel (2/3): главный график — Segmented показателя и детализации, «Подробнее →»
Panel (1/3): структура (кольцо + легенда) или «Требует внимания»
Panel: таблица или список (лучшие и худшие, ближайшие события)
```

Сначала ответ («сколько заработали»), потом «почему» (график, структура), потом «что сделать» (внимание, рекомендации).

### Список (товары, остатки, операции, история цен, акции)

```
PageHeader: название · счётчики («1 248 товаров, 12 без себестоимости») · [Excel] [главное действие]
Быстрые фильтры — Segmented или плашки со счётчиками (если они есть у раздела)
Panel flush: поиск и период слева, «Фильтры» справа → таблица → итоги / страницы
```

Групповые действия — полоса над таблицей, когда что-то выбрано.

### Страница объекта (товар, акция, выплата)

```
PageHeader: название объекта · артикул с копированием, статус Badge · [действия]
StatGrid: главные цифры объекта
Сетка Panel: график, юнит-экономика, цена, остатки, история
```

### Настройки и формы

Узкая колонка (`max-w-2xl`), группы — `Panel` с заголовком и строкой «на что влияет» (правило 15). Подпись над полем,
подсказка под ним, ошибка — у поля. Одна кнопка `primary` внизу группы.

## 6. Графики

- В `Panel`: заголовок — что показано, `description` — период, справа — «Подробнее →».
- Над графиком — `Segmented` показателя (слева) и детализации (справа, `size="sm"`).
- Линия — `type="monotone"`, `strokeWidth={2.5}`, заливка градиентом акцента от 28 % до 0 (пример — `/design`).
  Прошлый период — пунктир `muted`.
- Столбцы — `radius={[6, 6, 0, 0]}`, `maxBarSize={22}`; пара «сейчас / раньше» — `c1` и `c6`; плюс / минус —
  `ok` / `bad` по знаку.
- Сетка — только горизонтальная (`vertical={false}`, `stroke={line}`), оси без линий и засечек, подписи — 11 px `faint`.
- Ноль у прибыли и маржи — красная пунктирная линия (правки 06.11).
- Подсказка — `TipBox`; клик — подробности (правило 16).
- Кольцо — для структуры до 6 частей, рядом легенда с процентами; больше — столбцы по убыванию.
- Высота: главный график 256 px, второстепенный — 220 px.

## 7. Таблицы

- В `Panel flush`, прокрутка вбок — внутри панели (`overflow-x-auto`), страница вбок не прокручивается.
- Шапка — `bg-soft/60 text-xs text-muted font-medium`; строки — `py-3`, крайние ячейки `px-5`.
- Числа — справа, с единицами (`287 340 ₽`, `412 шт.`, `24,1 %`); «—» вместо пустого; минус — «−» и `text-bad`.
- Название товара — две строки: название (`font-medium`), артикул (`text-xs text-faint`, копирование).
- Статус — `Badge` с точкой. Действие строки — ссылка или `buttonClass('ghost','sm')` справа.
- Итог — последняя строка `font-semibold` на `bg-soft/60`.

## 8. Тексты и цифры

Русская типографика и правила текстов — `.claude/skills/impeccable/reference/project-ru.md` и `clarify.md`.
Коротко: «ёлочки», `1 234 567 ₽` с неразрывными пробелами, «−» для минуса, склонения («5 товаров»), кнопки —
глаголом («Применить цены»), ошибки — что случилось и что сделать.

## 9. Телефон (390 px)

- Показатели — по 2 в ряд, значки показателей скрыты, цифра 20 px.
- Панели в одну колонку; `PageHeader` — действия переносятся под заголовок.
- Таблица прокручивается внутри панели; на узких списках допустимы карточки вместо строк.
- Зона нажатия — не меньше 36 px по высоте (`h-9`), панель «Фильтры» — на всю ширину.

## 10. По разделам: что сделать при переделке

Общее для всех: `PageHeader` вместо своего заголовка, ключевые цифры — `Stat` / `StatGrid` вместо сетки
`gap-px` с подписями капсом (`home.tsx` → `Card`, `KeyFigures`), блоки — `Panel`, переключатели вида — `Segmented`
(сейчас в каждом разделе свой `pill` / `toggle`), статусы — `Badge`, кнопки — `buttonClass`, загрузка — `Skeleton`,
пусто — `EmptyState`.

| Раздел | Что поменять в первую очередь |
|---|---|
| **Главная** | `KeyFigures` → `StatGrid` со значками; график — заливка-градиент; «Требует внимания» и «Деньги и события» — `Panel` справа от графика на широком экране |
| **Аналитика** | Вкладки раздела под `PageHeader`; «Обзор бизнеса» — как главная; структура расходов (прибыльность) — кольцо + легенда; ABC — группы `Stat`, матрица в `Panel` |
| **Товары** | «Все товары» — список по шаблону §5, значки проблем — `Badge`; страница товара — шаблон «объект»; цены, акции, себестоимость — таблицы §7 |
| **Склады** | Сводка — `StatGrid` + «Требуют внимания»; остатки, вывоз — таблицы §7; поставки — статусы «Срочно / Скоро / Плановая» — `Badge` |
| **Операции** | Журнал — таблица §7 со статусами факт / план / просрочен — `Badge` с точкой; бюджеты — пары столбцов план / факт |
| **Финансы** | Обзор — по шаблону «обзор»; P&L строками — таблица §7 с итогами; выплаты — `Stat` (баланс, ближайшая выплата) + сверка `Badge` |
| **Планирование** | Обзор — «обзор»; календарь — дни на `card`, сегодня — рамка `accent`, разрыв — `bg-bad/10`; ДДС — таблица §7 |
| **Аккаунт и настройки** | Формы по §5, группы — `Panel` со строкой «на что влияет» |
| **Вход и регистрация** | Одна панель по центру на `bg`, кнопка `primary` во всю ширину |

Порядок — от главной: она задаёт образец остальным. Каждый раздел — отдельная задача; после переделки — снимки
обеих тем и 390 px.

## 12. Открытые вопросы владельцу

- **Боковое меню вместо верхнего** — почти во всех референсах. Сейчас меню сверху (решение 10.1). Можно сделать
  отдельной задачей: разделы слева со значками, подпункты раскрываются, на телефоне — выезжает.
- **Тема по умолчанию** — референсы в основном светлые; сейчас по умолчанию тёмная (правило 9).
