 1. Выпустить токен
 Токен — это уникальный ключ доступа, который позволяет использовать методы T ‑ API.
 Для работы с песочницей используйте токен Bearer TBankSandboxToken
.
 С помощью H2H-интеграции T ‑ API вы можете выпустить Access Token — он нужен только для прямой интеграции. Токен действует 90 дней с последнего использования, а при постоянном использовании активен бессрочно.
 Чтобы использовать защищенные методы 
 ,
также выпустите mTLS-сертификат. 
 Текущие TLS-сертификаты ( TLS ≠ mTLS ) T-API отозваны. Проверьте, что у вас настроено доверие к корневым сертификатам Минцифры .
 Выпуск 
 В личном кабинете Т-Бизнес: 
 Перейдите в раздел Интеграции → T‑API и нажмите Выпустить токен . 
 Введите IP-адреса всех компьютеров, с которых будете использовать токен. 
 Требования к IP-адресам
 Вы можете отключить проверку IP-адресов:
 Для малого и среднего бизнеса — выберите Отключить проверку адресов . Проверка отключится для выпускаемого токена. 
 Для крупных компаний — отправьте запрос с ИНН вашей компании на openapi@tbank.ru или обратитесь в чат или на горячую линию Т-Бизнеса. После отключения проверки перевыпустите токен.
 В блоке К чему будет доступ по API выберите операции, к которым хотите дать доступ . Для части операций доступен функционал ограничения счетов — напротив них есть плашка «Доступно ограничение счетов».
 Нажмите Выпустить токен . На правой части кнопки отображается количество выбранных доступов. 
 Скопируйте токен и сохраните его.
 После этого вы можете использовать токен для подключения ваших сервисов к Т ‑ Банку.
 Отредактировать токен не получится. Чтобы изменить IP-адрес или доступы, выпустите новый токен.
 Доступы 
 Доступ нужен, чтобы использовать методы T ‑ API. В описании каждого метода есть шаблон доступа.
 Пример 
 Чтобы использовать метод  Получить список этапов сделки , в личном кабинете нужно выбрать доступ «Управление номинальными счетами» — opensme/inn/{inn}/kpp/{kpp}/nominal-accounts/manage
.
 Чтобы получить или изменить доступ, перевыпустите токен в личном кабинете.
 Как предоставить доступ к личному кабинету своим сотрудникам 
 Ограничение счетов 
 Ограничение счетов — это функционал, который позволяет вам как директору компании ограничить доступ сотрудникам к определенным счетам на токене. Работает для продуктов Зарплатный проект и Счета .
 Например, у вашей компании есть несколько счетов для ведения бизнеса: один для выплат контрагентам, другой — для выплаты зарплат сотрудникам, и еще один — для прибыли.
Как директор вы хотите, чтобы ваши сотрудники, которые используют токен для работы с T-API, имели доступ только к тем счетам, которые нужны для их работы.
 Методы, для которых действует функционал ограничения счетов:
 Зарплатный проект — Создать черновик платежного реестра , Оплатить реестр .
 Счета — Получить счета v3 , Получить счета v4 .
 Как пользоваться 
 Директор:
 Настроить доступ для сотрудника
 Выпустить токен с доступом для сотрудника
 Сотрудник:
 Выпустить токен с доступом
 Отзыв токена 
 Перейдите в раздел Интеграции → T ‑ API и на плашке Токены нажмите Все токены .
 В блоке Приложения, у которых есть доступ к данным для входа выберите токен, который хотите удалить, и нажмите Удалить доступ .
