Шаг 3.4 — прибыль по товарам.

1. services/product_pnl.py: по каждому артикулу за период — количество, выручка, средняя цена,
   комиссия, логистика, прочие начисления (через posting_number), себестоимость (с НДС или без — по налоговому профилю, шаг 2.5),
   прибыль, маржа. Начисления без привязки к товару (хранение, подписки) — отдельной строкой
   «Не распределено», не размазывать молча.
2. GET /api/v1/pnl/by-product — сортировка по выручке/прибыли/марже/количеству, пагинация.
3. Вкладка «По товарам» на странице финансов: таблица, маржа цветом (<0 красный, 0–10 жёлтый,
   >10 зелёный), поиск, экспорт CSV, карточка товара по клику.
