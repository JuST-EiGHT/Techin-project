Шаг 10.3 — основа аналитики: одни и те же показатели, фильтры и сравнение для главной, «Аналитики», «Товаров» и
«Финансов» (`docs/SITEMAP.md` п. 1–3, 6; определения — `docs/BUSINESS_LOGIC.md` §10 «Показатели»).

Бэкенд: чистый модуль `engine/metrics.py` (ряды и итоги без БД) и `services/analytics.py`: выручка, прибыль, маржинальность,
заказы и штуки заказов (отправления 5.2 по дате создания, без отмен), продажи и возвраты в штуках и рублях
(`sales_daily`, начисления), средняя цена — по дням, неделям (пн–вс), месяцам; по магазину, товару, нескольким товарам,
категории; прошлый сопоставимый период (`dashboard.previous_period`); покрытие — дни без данных (не 0). Прибыль и маржа —
из P&L (`pnl_service`, кэш 5 минут), не новым расчётом.

Категории товаров: справочник категорий Ozon (`/v1/description-category/tree` — сверить с `docs/ozon/seller_api_2026-10.txt`,
обновить `docs/OZON_API.md`), названия у товаров; без категории — «Без категории».

API: GET `/analytics/metrics?date_from&date_to&granularity=day|week|month&product_id&category_id&compare=1` (по
текущему магазину), GET `/analytics/categories`.

Фронт: общий компонент фильтров `components/analytics.tsx` — период (пресеты и свои даты), товар (поиск), категория,
детализация, «сравнить с прошлым периодом», «обновлено …» (10.2); состояние — в адресе страницы (ссылкой можно
поделиться, «назад» работает). Графики — через `components/charts.tsx` (правило 16).

Тесты: ряды и итоги на эталонных данных (дни без данных, неполная неделя / месяц, сравнение, категория, заказы ≠ продажи),
совпадение выручки и прибыли с P&L за тот же период.
