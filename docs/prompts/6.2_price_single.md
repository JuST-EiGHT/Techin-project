Шаг 6.2 — изменение цены одного товара.

1. services/price_updater.py — update_single: текущая цена → проверки безопасности → если ошибки,
   отказ с записью в лог → dry-run возвращает предпросмотр без вызова Ozon → применение через
   /v1/product/import/prices → price_changes, audit_log, новый снепшот цены.
2. POST /api/v1/prices/preview → preview_id (живёт 15 минут);
   POST /api/v1/prices/apply принимает только preview_id. Применить без предпросмотра нельзя.
3. Модалка в панели товара: ввод → «Рассчитать последствия» → «было/станет», маржа,
   предупреждения → «Применить». После — уведомление «Ozon обработает за 1–3 минуты».
4. Тесты с моком Ozon: успех, отказ Ozon, блокировка проверкой, просроченный preview.
