Шаг 11.9 — «Реферальная программа»: награды промокодами (решение владельца 27.11.2026: скидка — только без минуса по
рентабельности; промокоды создаёт сервис в Ozon и дублирует у себя).

- Правило награды — настройка программы: за сколько выкупленных покупок друзей, скидка % или ₽, срок кода.
- Допустимая скидка: по каждому товару калькулятор 4.2 при цене со скидкой — прибыль не ниже «минимальной допустимой
  прибыли» (10.26); в акцию — только товары, где скидка не уводит в минус; что не прошло — списком с причиной.
- Акция «Скидка по промокоду» в Ozon (`/v1/seller-actions/create/voucher`, бета; товары — `/products/add`, коды —
  `/voucher/get` → CSV): предпросмотр → подтверждение → `audit_log` (правило 6), коды хранятся у нас; сверить параметры
  `voucher_parameters` (тип, количество, приватность) на реальном ключе.
- Выдача: участнику, которому положена награда, — следующий свободный код (одна запись, повторно не выдаётся), «Скопировать»
  и «Отправлено»; учёт: выдано, отправлено, использовано (по начислениям / отчётам, где Ozon это показывает), расход.
