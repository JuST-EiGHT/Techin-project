Шаг 6.3 — массовое изменение цен.

1. update_bulk: проверка каждого товара → группы «применится / с предупреждением / заблокировано»;
   dry-run; применение батчами по 100 с паузой 2 с, ошибка батча не останавливает остальные.
   Лимиты: ≤ 500 товаров, > 50 — confirm_large_batch, > 20% изменения запрещено.
2. POST /api/v1/prices/bulk/preview и /bulk/apply.
3. /dashboard/prices/bulk — мастер из 5 шагов: стратегия (целевая маржа / +X% / мин. цена + X%),
   выбор товаров, предпросмотр, подтверждение (> 50 — ввести «ПОДТВЕРЖДАЮ»), прогресс по батчам.
