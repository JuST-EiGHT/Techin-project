Шаг 4.2 — калькулятор минимальной и целевой цены. Формула — docs/BUSINESS_LOGIC.md §4.

1. engine/price_calculator.py — PriceParams, PriceResult (min_price, target_price, текущая маржа,
   маржа в акции, прибыльно/нет). Знаменатель ≤ 0 → понятная ошибка. Тесты с ручным пересчётом.
2. POST /api/v1/price/calculate (product_id + переопределения), GET /api/v1/price/suggestions
   (самые убыточные / недооценённые).
3. В боковой панели товара — блок «Расчёт цены» с полями реклама % и целевая маржа %,
   комиссия и логистика подставляются из данных Ozon по товару. Налог и НДС с продажи — по
   налоговому профилю (шаг 2.5): то, что берётся с выручки, — доля в знаменателе формулы.
   Реклама % и целевая маржа — настройки пользователя (сохраняются); цифры магазина владельца
   из BUSINESS_LOGIC §4 — не умолчания.
4. /dashboard/prices — таблица: цена, мин., целевая, маржа, маржа в акции; цена ниже минимальной
   подсвечена красным.
5. Теперь пересчитай margin_in_promo из шага 1.5 этой формулой.
