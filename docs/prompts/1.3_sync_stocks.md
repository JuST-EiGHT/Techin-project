Шаг 1.3 — склады и остатки.

1. Миграции warehouses (user_id, ozon_warehouse_id, name, type FBO/FBS, is_active) и
   product_stocks (product_id, warehouse_id, snapshot_at, present, reserved, in_transit).
2. services/sync/stocks.py — /v1/warehouse/list и /v4/product/info/stocks (батчами).
3. Расчёт avg_daily_sales (30 дней), days_of_supply и статуса critical <7 / low <14 /
   normal / excess >60. Пока продаж в БД нет — days_of_supply = null, не 0.
4. Celery раз в 30 минут.
5. API: GET /api/v1/warehouses, GET /api/v1/stocks (фильтры warehouse_id, status, product_id).
6. Страница /dashboard/warehouses — таблица с цветом по статусу.
Поле `total` в ответах Ozon не использовать (отключат 23.11.2026) — только `total_items`, см. docs/OZON_API.md.

> По документации Ozon (docs/ozon/): `/v1/warehouse/list` отключён — FBS/rFBS-склады в `/v2/warehouse/list`;
> остатки FBO по кластерам и складам — `/v1/analytics/stocks`. См. docs/OZON_API.md.
