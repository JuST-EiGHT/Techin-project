Шаг 7.1 — детектор аномалий. Пороги — docs/BUSINESS_LOGIC.md §7.

1. Миграция anomalies (тип, severity yellow|red, товар/склад, метрика до/после, порог,
   detected_at, resolved_at, is_acknowledged).
2. engine/anomaly_detector.py — 8 детекторов, каждый отдельной функцией с тестом.
   Не дублировать активную аномалию того же типа; учитывать выходные при оценке падения продаж.
   Дни без данных (пропуски синхронизации, docs/DATA_HISTORY.md) — не падение продаж и не нулевой остаток.
3. Celery раз в час: поиск новых и автозакрытие тех, где метрика вернулась в норму.
4. GET /api/v1/anomalies, GET /anomalies/count, POST /{id}/acknowledge.
