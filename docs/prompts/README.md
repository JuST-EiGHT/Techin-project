# Промпты по шагам

Отправляй в Claude Code по одному, в порядке из docs/ROADMAP.md.
Первым — `00_start.md`. Весь контекст проекта Claude Code берёт из CLAUDE.md и docs/,
поэтому промпты короткие.

После каждого шага:
1. Попроси показать, что изменилось, и прогони тесты (`pytest`).
2. Проверь руками в браузере, если шаг затрагивает интерфейс.
3. Убедись, что статус обновлён в CLAUDE.md и docs/ROADMAP.md.
4. Сделай коммит (или попроси Claude Code его сделать).
