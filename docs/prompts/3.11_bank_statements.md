Шаг 3.11 — банки: выписка файлом (формат 1С), выплаты Ozon ↔ поступления на счёт.
План — docs/MONEY.md §4 и §6.

Необязательный источник факта для «Планирования» (шаги 3.8–3.10 работают и без банка). Запасной путь
для любого банка; прямые интеграции по API — шаг 3.12, они пишут в те же таблицы.

1. Миграции `bank_transactions` (дата, сумма + приход / − расход, контрагент, ИНН, счёт контрагента,
   назначение, номер документа, банковский id операции, источник, raw_json) и `bank_balances`
   (остаток на дату); счёт банка — это `money_accounts` из 3.8 (+ БИК, номер счёта, источник bank).
   Правило 12: операции не удаляются и не перезаписываются; повторная загрузка того же периода не
   создаёт дублей (ключ — id операции банка, для файла — номер + дата + сумма + счёт).
2. `integrations/bank/statement_1c.py` — разбор файла обмена с 1С (1CClientBankExchange, кодировки
   windows-1251 и utf-8, версии 1.02/1.03): секции РасчСчет и Документ, приход или расход — по тому,
   наш ли счёт у плательщика. Понятные ошибки на русском. Тестовые файлы — синтетические, без
   реальных выписок (правило 11).
3. Операции банка становятся операциями планирования (`money_operations`, источник bank). Дубли с
   введёнными вручную — предложить объединить (сумма, дата ± 3 дня, контрагент), не объединять молча.
4. Поступления от маркетплейсов — по ИНН плательщика из справочника (Ozon — ООО «Интернет Решения»,
   ИНН 7704217370; справочник — данные, не код). Поступление от Ozon — факт выплаты Ozon (шаг 3.6):
   одна операция, а не две; сверка «выплата по данным Ozon ↔ поступление на счёт» по сумме и дате,
   расхождение — в отчёт (позже — аномалия, шаг 7.1).
5. Отчёт XLSX (шаг 2.2): если найдено поступление от Ozon за его период — подсказка для «сколько
   реально пришло» (manual_total), сохраняется только по подтверждению пользователя.
6. API: POST `/api/v1/bank/statements/upload` (предпросмотр: счёт, период, сколько новых операций,
   дублей и совпадений с ручными), GET `/api/v1/bank/accounts`, GET `/api/v1/bank/transactions`.
7. В «Планировании» → «Счета»: загрузка выписки (инструкция «где взять файл 1С в интернет-банке»),
   у счёта — источник «из банка».

Тесты: разбор файла, кодировки, дубли при повторной загрузке, приход/расход, чужие счета, поступление
от Ozon закрывает выплату без двойного счёта, совпадения с ручными операциями.
