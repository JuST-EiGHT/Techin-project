Шаг 3.3 — страница /dashboard/finance. Визуальный ориентир — reference/ozon_calculator.html
(структура, цвета, блоки) — пользователь к нему привык.

1. Выбор периода: «Эта неделя», «Этот месяц», «Прошлый месяц», свой диапазон;
   или открыть конкретный загруженный отчёт.
2. Полоса из 5 главных цифр: продано (выручка), получено от Ozon, себестоимость с НДС
   (у кого поставщик получает деньги после продажи — это «долг поставщику»; подпись —
   настройка пользователя, правило 13), налог, остаток + маржа (самый заметный блок).
3. Поле «Сумма от Ozon» с ручной правкой и кнопкой «↩ Авто»; пересчёт без перезагрузки;
   для открытого отчёта правка сохраняется (PATCH из шага 2.2).
4. Таблица «Начисления по типам и P&L»: доходы и расходы, у каждой группы проценты
   в сумме 100%; блок P&L с процентом от выручки; прибыль синим, остаток зелёным/красным.
5. Бейдж источника: «Из XLSX» / «Из API ⚠» с пояснением.
6. Параметры (НДС, УСН) в сворачиваемом блоке, пересчёт сразу.
7. График по дням (Recharts) — только если есть данные по дням, без графиков ради графиков.
8. P&L — по начислениям. Деньги на счёте (ДДС) — отдельный отчёт в разделе «Деньги»
   (шаги 3.6–3.10, docs/MONEY.md); не смешивать, подписывать.
