Шаг 0.5 — каркас интерфейса: меню разделов с выпадающими списками, меню аккаунта,
основные настройки и переключение тёмной и светлой темы.

1. Меню разделов в шапке. У основного раздела при наведении (и по нажатию — для телефона и
   планшета) под кнопкой раскрывается список его страниц; закрывается при уходе курсора
   (с небольшой задержкой, чтобы не мигало), Esc и клике мимо; работает с клавиатуры.
   Структура — один конфиг (src/lib/nav.ts), страница появляется в меню, только когда она
   сделана:
   - Главная (дашборд, шаг 3.11);
   - Финансы ▾ — P&L (3.3), по товарам (3.4), отчёты Ozon (2.2 ✅), себестоимость (2.3);
   - Деньги ▾ — счета и операции (3.6), ДДС (3.9), платёжный календарь (3.10), статьи и правила (3.8);
   - Товары ▾ — товары (4.1), цены и минимальная цена (4.2), история цен (6.4);
   - Акции ▾ — все акции (1.5 ✅), добавленные автоматически (1.5 ✅, вкладка страницы акций
     по ссылке), история участия (4.3);
   - Склады ▾ — остатки по складам (1.3 ✅), кандидаты на вывоз (5.1), поставки (5.2).
   Активный раздел подсвечен и на его подстраницах. На узком экране — меню-«бургер».
2. Меню аккаунта справа вверху: иконка (инициалы) и стрелка вниз ▾ — понятно, что там
   список. По нажатию: имя и email, «Аккаунт», «API-ключи Ozon» (есть), «Банки» (появится
   на шаге 3.7), «Основные настройки», «Уведомления» (7.3), «Тариф» (8.1), «Выйти» —
   кнопка «Выйти» переезжает сюда из шапки. Статус синхронизации остаётся в шапке.
3. /dashboard/settings/account — имя (можно изменить), email; смена пароля (текущий + новый,
   после смены — выход на всех устройствах через чёрный список токенов). Бэкенд:
   PATCH /api/v1/auth/me, POST /api/v1/auth/change-password, ошибки по-русски.
4. /dashboard/settings — «Основные настройки» сервиса. Таблица user_settings (миграция),
   API GET/PATCH /api/v1/settings. Разделы:
   - Внешний вид: тема — тёмная (по умолчанию) / светлая / как в системе;
   - Расчёты по умолчанию (правило 13 — у каждого продавца свои): коэффициент НДС к
     себестоимости (1.22), налог — от прибыли или от дохода и ставка (у владельца — 20 % от
     прибыли). Новые отчёты (шаг 2.2) берут значения отсюда, а не из констант; в отчёте их
     по-прежнему можно поменять;
   - места для разделов следующих шагов (уведомления, банки) — ссылками, когда появятся.
5. Темы. Цвета — CSS-переменные (`:root` — тёмная, `[data-theme="light"]` — светлая), в
   Tailwind — токены bg, card, line, fg, muted, accent, ok, bad, warn через
   `rgb(var(--…) / <alpha-value>)`, чтобы работали `bg-accent/15` и т. п. Заменить жёсткие
   цвета в существующих страницах (`text-slate-*`, `text-white`, `bg-black/60`) на токены.
   Тема применяется до отрисовки (скрипт в `<head>` читает localStorage), без вспышки тёмного;
   выбор сохраняется и в user_settings — одинаково на всех устройствах. Графики (Recharts)
   берут цвета из тех же переменных. Светлая палитра (предложение — утвердить с владельцем):
   фон #f6f7fb, карточки #ffffff, рамки #e3e6ee, текст #1a1d27, второстепенный текст
   #5b6275, акцент #2f6fe4, зелёный #16a34a, красный #dc2626, жёлтый #b45309 — контраст
   текста не ниже WCAG AA.
6. Проверить вручную в браузере обе темы на всех существующих страницах, меню мышью,
   с клавиатуры и на узком экране; скриншоты.

Тесты: API настроек и смены пароля (неверный текущий, слабый новый, токены старой сессии
отозваны), значения по умолчанию для новых отчётов берутся из настроек.
