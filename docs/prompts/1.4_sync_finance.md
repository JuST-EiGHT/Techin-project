Шаг 1.4 — финансовые начисления из API. /v3/finance/transaction/list отключён —
использовать /v1/finance/accrual/* (см. docs/OZON_API.md, перепроверь в документации Ozon).

1. Миграции accrual_types (type_id, name_ru, category доход/расход) и accruals
   (user_id, product_id nullable, posting_number, accrual_type_id, accrual_date, amount,
   source 'api'|'xlsx', raw_json). Защита от дублей при повторной синхронизации.
2. services/sync/finance.py: справочник типов; начисления за период с разбивкой на месяцы
   и пагинацией; привязка к товару через posting_number; агрегаты по дням;
   get_missing_periods — какие дни ещё не загружены.
3. Celery: каждые 6 часов — вчера и сегодня; разово при подключении ключа — последние 90 дней.
4. API: GET /api/v1/finance/accruals, GET /api/v1/finance/accruals/by-day, POST /api/v1/finance/sync.
5. Во всех ответах с данными из API — поле data_source="api" и предупреждение, что данные
   могут расходиться с личным кабинетом, для точного P&L — загрузить XLSX.
