Шаг 3.8 — статьи ДДС и правила разнесения операций. План — docs/MONEY.md §5.

1. cash_categories: статьи пользователя (приход / расход, группа). При первом входе в раздел —
   шаблон для селлера: поступления от маркетплейсов, прочие поступления, закупка товара,
   логистика и фулфилмент, реклама, налоги и взносы, зарплата, аренда, банк и эквайринг,
   перевод между своими счетами (не доход и не расход), прочее. Пользователь меняет как хочет.
2. categorization_rules: условия (ИНН или название контрагента, слова в назначении,
   направление, диапазон суммы) → статья; приоритет правил. Встроенные правила: маркетплейсы
   по ИНН, переводы между своими счетами, налоги по реквизитам казначейства.
3. Разметка: новые операции размечаются правилами; ручная разметка важнее правил и не
   перезаписывается; из ручной разметки — предложение «создать правило для всех операций
   этого контрагента». Пересчёт по новому правилу — только неразмеченных вручную.
4. API: CRUD статей и правил, PATCH /api/v1/bank/transactions/{id} (статья, комментарий),
   массовая разметка.
5. На /dashboard/money: статья у каждой операции, фильтр «без статьи», правила.

Тесты: приоритет правил, ручная разметка не теряется, переводы между своими счетами.
