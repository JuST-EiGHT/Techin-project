Шаг 3.7 — главная `/dashboard`: дашборд Ozon. Состав — docs/MONEY.md §5.

Только данные Ozon (решение владельца): ни прогноза остатка, ни внешних операций — это отдельный
обзор планирования (шаг 3.10). Продавцу, которому не нужно планирование, главной достаточно.

1. GET `/api/v1/dashboard/ozon` (период): продано, начислено к получению, прибыль и маржа (P&L с
   источником XLSX / API и бейджем), на балансе у Ozon, следующая выплата (дата и сумма из 3.6),
   сравнение с прошлым таким же периодом; ряды для графиков. Быстро: из сохранённых итогов
   (pnl_snapshots, шаг 3.2), кэш как у P&L.
2. Цифры сверху (как полоса на странице P&L) и графики (Recharts): выручка по дням / неделям с
   прошлым периодом; выплаты Ozon по неделям — факт и прогноз (как на странице «Выплаты Ozon»).
   Клик по цифре ведёт на свою страницу (P&L, выплаты, отчёты).
3. Пустые состояния с подсказкой, что подключить: ключ Ozon, отчёты XLSX. Нет данных — «нет данных»,
   а не 0 (правило 12). Налог не задан — как на странице P&L.
4. Виджеты следующих фаз (остатки — 5.1, изменения цен — 6.4, аномалии — 7.2) добавляются на
   главную в своих шагах.
