Шаг 2.4 — шаблоны для загрузки себестоимости: скачал → заполнил → загрузил.

Себестоимость каждый пользователь (и владелец тоже) вносит сам — по шаблону, который сервис
отдаёт уже с его товарами. Файл, скачанный из сервиса и загруженный обратно, принимается
без ошибок (правило 14). Сейчас (2.3) есть только CSV-строка заголовков с примером, а пустая
себестоимость при импорте — ошибка, поэтому шаблон «со всеми товарами» сейчас не работает.

1. Общий модуль шаблонов `services/templates/` — им пользуются следующие шаги (плановые
   платежи 3.10, массовое изменение цен 6.3):
   - описание колонок: заголовок, ключ, обязательность, тип (текст / число / ставка / дата),
     справочная ли колонка (не читается при загрузке), пример, пояснение;
   - XLSX (openpyxl): лист с таблицей — заголовок жирным, закреплённая строка заголовка,
     ширины, у артикула формат «Текст» (чтобы Excel не превращал `6001` в число, а `1-2` в дату),
     проверка данных Excel: цена > 0, ставка НДС — выпадающий список, дата — дата;
     справочные колонки серым; лист «Инструкция»: что заполнять, примеры, частые ошибки;
   - CSV — те же колонки (UTF-8 с BOM, разделитель «;», запятая в дробных);
   - разбор загруженного файла по тому же описанию — колонки по заголовкам (правило 4),
     лист «Инструкция» и чужие листы не мешают.
2. GET `/api/v1/costs/template?format=xlsx|csv&rows=all|missing|empty`:
   - all — все известные товары (каталог Ozon, товары из отчётов, справочник) с текущими
     ценами — это же и выгрузка справочника для правки;
   - missing — только товары без себестоимости;
   - empty — пустой шаблон с одной строкой-примером на листе «Инструкция», не в таблице.
   Колонки: Артикул (offer_id) | Название (справочно) | SKU (справочно) | Себестоимость за шт.
   без НДС | Ставка НДС поставщика | Действует с | Комментарий. Сортировка — как на странице
   (без цены и самые продаваемые — первыми).
3. Импорт (`services/cost_import.py`) поверх общего модуля:
   - пустая себестоимость → «пропущено», не ошибка; такая же цена → «без изменений»;
   - ставка НДС поставщика: «22 %», «22», «0,22», «1,22» → коэффициент 1,22; «без НДС» / «0» → 1;
     пусто — как в налоговом профиле (шаг 2.5; до него — как в «Основных настройках»);
   - колонка «Себестоимость с НДС» вместо «без НДС» — пересчёт по ставке, в предпросмотре
     видно обе цены;
   - артикул, который Excel превратил в число (`6001.0`) или дату, — привести к тексту или
     ошибка с подсказкой «задайте колонке формат Текст»;
   - формула без сохранённого значения → «В ячейке формула без значения — откройте файл
     в Excel и сохраните»;
   - текст ошибки — что не так и как исправить, с номером строки Excel.
4. «Скачать строки с ошибками» — тот же шаблон только с ошибочными строками и колонкой
   «Ошибка»: исправил → загрузил снова.
5. Страница /dashboard/costs: вместо ссылки «Скачать шаблон CSV» — блок из трёх шагов:
   «1. Скачайте шаблон (с вашими товарами / только без себестоимости / пустой; Excel или CSV)
   → 2. Заполните колонку «Себестоимость» → 3. Загрузите — покажем, что изменится».
   Есть товары без себестоимости — баннер с кнопкой «Скачать шаблон с этими товарами»
   (на странице себестоимости и в отчёте, у таблицы «не найдена себестоимость»).
6. Сид-скрипт `backend/scripts/seed_costs.py` и монтирование `./reference:/reference` в
   docker-compose убрать: данные владельца в продукт не загружаются, он вносит их сам, как
   любой пользователь. `reference/cost_prices.csv` остаётся только для тестов (эталоны
   BUSINESS_LOGIC); CLAUDE.md — поправить.
7. Тесты «туда и обратно»:
   - скачанный шаблон (all, missing, empty; xlsx и csv) загружается без ошибок — строки
     «пропущено» или «без изменений»;
   - шаблон, заполненный через openpyxl как пользователь, применяется; выгрузка текущих цен →
     загрузка без правок → 0 изменений;
   - CSV, пересохранённый Excel (Windows-1251, «;»), XLSX из LibreOffice / Google Таблиц
     (если отличается — фикстура);
   - артикулы-числа и даты, ставки в разных записях, «Себестоимость с НДС», формулы;
   - файл ошибок → исправили → загрузили.
   Живая проверка в браузере: скачать шаблон, заполнить, загрузить (обе темы).
