Шаг 10.2 — кнопка «Синхронизация» в шапке (`docs/SITEMAP.md`, «Шапка»): обновить данные из Ozon одной кнопкой и видеть,
насколько они свежие.

Вместо «Обновлено N минут назад / Обновить сейчас» (только товары, шаг 1.2) — кнопка «Синхронизация» с состоянием:
всё свежее / идёт загрузка / есть ошибка. По нажатию — окно по видам данных текущего магазина: товары и цены, остатки,
начисления, баланс и выплаты, акции, отправления, банк (если подключён); у каждого — когда обновлено, идёт ли сейчас,
ошибка простыми словами и что сделать (ключ истёк — ссылка в «Интеграции»), «Обновить» по одному виду и «Обновить всё».

Бэкенд: POST `/sync/all` — в очередь все виды текущего магазина (идущие — пропустить, ответ — что поставлено, что уже
идёт); GET `/sync/status` уже отдаёт все виды — добавить общее состояние и «самые старые данные». Лимиты Ozon — как в
плановых задачах (не чаще раза в N минут на вид, кнопка честно говорит «уже обновлено недавно»).

Общий компонент «Обновлено …» — для «Аналитики» (10.7) и «Требует внимания» (10.5: ошибки синхронизации — оттуда).
Тесты: «Обновить всё» ставит только не идущие, статус по видам, ошибки без секретов. Playwright: обе темы, 390 px.
