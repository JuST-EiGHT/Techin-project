Шаг 8.5 — банки, где сервису нужно стать партнёром банка. Сведения — docs/MONEY.md §4.

Сбер (СберБизнес API, СберБизнес ID, сертификаты электронной подписи), Альфа, ВТБ и другие
крупные банки дают доступ к выпискам платформам по договору. Шаг делается, когда у сервиса
есть юрлицо и договоры с банками.

1. Для каждого банка — провайдер BankProvider (шаг 3.7), подключение пользователем по
   OAuth / партнёрской авторизации банка, только права на чтение выписок.
2. Сертификаты и секреты сервиса — в хранилище секретов сервера, не в репозитории.
3. До подключения банка его клиенты пользуются загрузкой выписки файлом (шаг 3.6).
