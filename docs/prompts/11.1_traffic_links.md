Шаг 11.1 — раздел «Продвижение», префикс UTM_CAMPAIGN и конструктор ссылок «Внешнего трафика» (запрос владельца
17.11.2026; карта — `docs/SITEMAP.md` §12).

Как у Ozon (база знаний, «Внешний трафик»; кабинет — https://seller.ozon.ru/app/advertisement/vendor-traffic): API нет.
Ozon узнаёт кампанию только по `utm_campaign` = префикс продавца `vendor_org_XXXXX` (+ по желанию `_название`); без
префикса переходы не попадут в статистику. Ссылки — только ozon.ru / ozon.kz / ozon.by и только товар (`/product/`),
магазин (`/product/seller/`), бренд (`/brand/`), акция или подборка (`/highlight/`).

Сделать:
- Настройка магазина «Префикс для метки UTM_CAMPAIGN» («Настройки → Продвижение», миграция по дате): где взять (ссылка на
  кабинет), зачем (правило 15), проверка формата `vendor_org_<цифры>`; данные владельца не зашивать (правило 13). Нет
  префикса — конструктор подсказывает задать его, ссылки не собирает.
- `engine/traffic_links` (чистый): разбор и проверка ссылки (домен, раздел, ошибка понятным текстом), сборка UTM (существующие
  параметры ссылки сохраняются, наши метки заменяют свои), каналы как у Ozon — Яндекс (Директ, РСЯ), myTarget, VK реклама,
  «Социальные сети и платформы», «Другое»; у сетей `utm_source` — сам, макросы сети — по желанию. Название кампании
  обязательно; `utm_source` и `utm_medium` — подсказка «без них в отчёте не будет разбивки»; term, content — по желанию.
- Ввод: товары из каталога (поиск, выбор многих; ссылка — `https://www.ozon.ru/product/<sku>/`) или список ссылок по одной
  в строке, до 100 за раз; у неподходящей строки — ошибка, остальные собираются.
- Результат: список ссылок — `CopyText`, Excel / CSV, QR-код (генерация на фронте, без внешних сервисов).
- Шапка: пункт «Продвижение ▾» между «Товарами» и «Складами» (`lib/nav.ts`), подраздел «Ссылки с UTM»
  (`/dashboard/advertising/links`); проверить, что меню помещается с 1280 px.
- Данные — по магазину (`get_current_store`). Сохранение и история ссылок — 11.2 (здесь — только сборка).

Тесты: проверка ссылок (домены, разделы, мусор, kz / by, параметры), сборка UTM и макросов, префикс, лимит 100.
Playwright: обе темы, 390 px, без прокрутки вбок.
