Шаг 8.4 — деплой на VPS (Timeweb Cloud или аналог, Ubuntu).

docker-compose.prod.yml (без маунтов кода, restart, лимиты памяти), Nginx с HTTPS
(Let's Encrypt, редирект 80→443, заголовки безопасности, gzip), scripts/setup.sh для
первого запуска и scripts/deploy.sh для обновления (с проверкой /health), бэкап Postgres
в Object Storage: каждые 6 часов (30 копий) + ежедневные за 30 дней + ежемесячные за 12 месяцев,
раз в месяц — проверка восстановления в отдельную БД (docs/DATA_HISTORY.md), Sentry, внешний
мониторинг доступности, .env.prod.example, README-DEPLOY.md с пошаговой инструкцией с нуля.

Сразу после запуска подключить ключ Ozon своего магазина и загрузить прошлые XLSX-отчёты —
с этого дня копится история цен, остатков и акций (docs/DATA_HISTORY.md, «Когда история
начинает копиться»). До деплоя это не нужно.
Данные пользователей из РФ — сервер в РФ (152-ФЗ).
