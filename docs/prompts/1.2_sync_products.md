Шаг 1.2 — синхронизация товаров и цен из Ozon в БД.

1. Миграции: products (user_id, ozon_product_id, ozon_sku, offer_id, name, category_id, barcode,
   vat, is_archived, synced_at; уникальность user_id+ozon_product_id) и product_prices
   (снепшоты: product_id, snapshot_at, price, min_price, old_price, marketing_price,
   commission_pct, acquiring_pct, auto_action_enabled, price_index).
2. services/sync/products.py — /v3/product/list с пагинацией по last_id, детали и цены батчами
   через /v5/product/info/prices; upsert товаров; новый снепшот цены только если что-то изменилось.
   Вернуть счётчики: новых / обновлённых / без изменений.
3. Celery-задача sync_products_for_user + Celery Beat раз в час для всех активных ключей.
   Ошибка у одного пользователя не должна валить задачу для остальных.
4. API: POST /api/v1/sync/products (ручной запуск), GET /api/v1/sync/status.
5. Фронт: в шапке dashboard «Обновлено N минут назад» и кнопка «Обновить сейчас».
6. Тесты на записанных (фейковых) ответах Ozon, без реальной сети.
