Шаг 3.2 — P&L API.

1. services/pnl_service.py — get_pnl(user, date_from, date_to, source='auto'|'xlsx'|'api',
   vat_multiplier, tax_rate, manual_total). При auto: если за период есть XLSX — берём его,
   иначе данные API с предупреждением. Всегда возвращать, какой источник использован.
2. GET /api/v1/pnl, /pnl/by-day, /pnl/periods (за какие периоды есть данные).
3. Кэш в Redis на 5 минут, ключ — пользователь + параметры; сбрасывать при загрузке отчёта
   или синхронизации.
4. pnl_snapshots — сохранять P&L закрытых месяцев для быстрого дашборда. В снимке — calculated_at;
   помечать устаревшим и пересчитывать по правилам docs/DATA_HISTORY.md («Пересчёт сохранённых
   итогов»): себестоимость, отчёты или начисления за период изменились.
