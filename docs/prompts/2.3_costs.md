Шаг 2.3 — справочник себестоимости в БД.

1. Миграция product_costs: user_id, offer_id, cost_price (без НДС), vat_multiplier (1.22),
   effective_from, note, created_at. История: новая цена — новая запись, старая остаётся,
   чтобы прошлые P&L не менялись. Таблицу products на этом шаге не требуй — связь по offer_id
   (товары из API появятся в фазе 1).
2. Сид-скрипт: загрузить reference/cost_prices.csv для пользователя.
3. API: GET /api/v1/costs, PUT /api/v1/costs/{offer_id}, GET /{offer_id}/history,
   POST /api/v1/costs/import (CSV/XLSX: offer_id, cost_price, vat_multiplier, note) с
   предпросмотром и отчётом «обновлено X, ошибок Y». Валидация: цена > 0, коэффициент 1.0–2.0.
4. Реализуй CostProvider из шага 2.1 поверх БД (цена на дату периода отчёта).
5. Страница /dashboard/costs: таблица, редактирование в ячейке, импорт, фильтр «без себестоимости»,
   список артикулов, которые встречались в отчётах, но не имеют цены.
