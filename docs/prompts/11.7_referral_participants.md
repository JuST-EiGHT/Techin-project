Шаг 11.7 — «Продвижение → Реферальная программа»: участники и их личные ссылки (решение владельца 27.11.2026).

Идея владельца: тем, кто оставил отзыв, — личная ссылка; друзья купили по ней — человеку награда (промокод, 11.9). Без
подписок Premium и «Управление отзывами»: отзывы сервис через API не видит, чат первым при FBO продавец не начинает —
участника добавляет продавец, ссылку отправляет сам (он может написать тому, кто оставил отзыв) и отмечает «Отправлено».

Сделать:
- Отдельная страница `/dashboard/advertising/referral` в «Продвижении» (`lib/nav.ts`), PageHeader «Реферальная
  программа», «как это работает» — в «?» (участник → ссылка → отправили → друзья купили (11.8) → промокод (11.9)).
- Настройки программы магазина (свои у каждого магазина, правило 13): название кампании (идёт в utm_campaign после
  префикса, по умолчанию `friends`), utm_source и utm_medium (по умолчанию `referral` / `friend`), ссылка на магазин в Ozon
  (для участников «ссылка на магазин»). Нет префикса UTM_CAMPAIGN — сначала он (11.1).
- Участник: товар из каталога (необязательно), имя из отзыва, дата отзыва, заметка; куда ведёт ссылка — товар или
  магазин. Код участника — короткий, уникальный в магазине (без похожих символов), в `utm_content` = `ref_<код>`; ссылка —
  через историю ссылок 11.2 (одна запись `traffic_links`, видна и в «Созданных ссылках»).
- «Отправлено» — дата и канал (чат Ozon, вне Ozon, ответ на отзыв, другое), заметка; «Отменить отметку». Статус — по
  последнему событию; события участника — только добавление (правило 12). Имя и заметку можно поправить (справочник —
  на месте, в журнале действий). Удаление — отметка и «Вернуть».
- Список: быстрые вкладки (все / не отправлены / отправлены / удалённые) со счётчиками, поиск (имя, артикул, код),
  период добавления, «Фильтры» (канал, товар), сортировка `SortTh`, ссылка — `CopyText`, QR, Excel.
- События ленты (10.11): участник добавлен, ссылка отправлена, удалён / возвращён.

Проверка: тесты API и сценария (код уникален, ссылка с кодом, отправлено и отмена, магазины не пересекаются, удаление и
возврат, Excel); сервис поднят (skill `verify`), сценарий в браузере — обе темы, 390 px.
