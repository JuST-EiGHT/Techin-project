Шаг 4.2a — юнит-экономика как у Ozon (решение владельца 10.11.2026 после сверки с «Юнит-экономикой» кабинета Ozon:
статьи Ozon — продажи с баллами и партнёрами, вознаграждение, эквайринг, доставка и размещение, возвраты, доп. услуги и
штрафы, продвижение и реклама). Сделать пункты 1, 2 и 6 из разбора; 3, 4, 5, 7 — позже, по решению владельца.

1. Реклама по факту у товара. Доля продвижения от продаж товара (выручка + баллы + партнёры) за 30 дней, не продавался —
   за 90, как логистика. «Оплата за клик» и «Продвижение с оплатой за заказ» Ozon начисляет по кампании, без товара
   (проверено на отчётах владельца) — их доля в продажах магазина добавляется каждому товару (оценка, подписано). Товар
   без продаж — вся реклама магазина / продажи. Настройка «реклама %» — только когда данных нет; своё значение у товара
   (product_price_extras) важнее факта.
2. Хранение по товару. Ozon начисляет «Размещение на складе» одной строкой в день на весь магазин; отчёт «Стоимость
   размещения по товарам» — `/v1/report/placement/by-products/create` (≤ 31 дня, ≤ 5 в день) → код → `/v1/report/info` →
   файл. Файл хранить (ozon_documents), строки — storage_costs; строку хранения за день делить между товарами в долях
   отчёта — в «Прибыли по товарам», юнит-экономике, «Аналитике прибыльности» и расчёте цены (₽ на проданную штуку).
   Отчёта нет — в прибыли по товарам «Не распределено», в расчёте цены — среднее по магазину (оценка). Колонок отчёта в
   документации нет — разбирать по заголовкам (правило 4), неразобранный файл не терять и разбирать снова.
6. Возвраты отдельно. Обратная логистика и обработка возвратов, отмен и невыкупов — своей группой «Возвраты», не в
   логистике (P&L 10.22 — как раньше, «Логистика»). Выкуп: отправление с обратной логистикой без выручки и возврата
   выручки — невыкуп; выкуп = продано / (продано + невыкуплено). В расчёте цены — строка «Возвраты и невыкупы» на 1 шт. и
   подсказка с выкупом.

Тесты: группы на названиях статей из реальных отчётов, выкуп, доли хранения (копейки сходятся, ближайший день), разбор
XLSX и CSV, запрос → код → файл → строки, лимит запросов в день, расчёт цены с фактом, настройка — только без данных.
