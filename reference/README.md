# reference/

- `ozon_calculator.html` — рабочий браузерный калькулятор P&L, которым владелец пользуется
  сейчас. Это эталон логики: ReportDetector, AccrualReportParser, RealizationReportParser,
  PnLEngine, проценты по группам, ручная сумма. Переносить в Python (шаги 2.1 и 3.1),
  поведение не менять. Открывается двойным кликом в браузере.
- `cost_prices.csv` — себестоимость 78 артикулов без НДС. Источник для сида (шаг 2.3).
